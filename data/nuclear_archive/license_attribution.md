# NUBASE2020 attribution and license evidence

F.G. Kondev, M. Wang, W.J. Huang, S. Naimi, and G. Audi, *The NUBASE2020 evaluation of nuclear physics properties*, Chinese Physics C 45, 030001 (2021), [DOI 10.1088/1674-1137/abddae](https://doi.org/10.1088/1674-1137/abddae).

The [official publisher PDF](https://csnsdoc.ihep.ac.cn/fileZGWLC/journal/article/zgwlc/2021/3/PDF/The-NUBASE2020-1.pdf), page 030001-1, contains this notice:

> Content from this work may be used under the terms of the Creative Commons Attribution 3.0 licence.

That same notice requires continued attribution to the authors, title, journal citation, and DOI. The [publisher article's reuse policy](https://cpc.ihep.ac.cn/article/doi/10.1088/1674-1137/abddae) also discusses CC BY 3.0 reuse. The [license](https://creativecommons.org/licenses/by/3.0/) permits sharing and adaptation subject to its terms. No publisher endorsement is claimed.

The official companion ASCII table was obtained from the [IAEA Atomic Mass Data Center dissemination page](https://www-nds.iaea.org/amdc/), which requests citation of the evaluation paper. Its original header supplies that citation; it does not contain a separate license notice. The confirmed license belongs to the published work. This distinction is retained instead of inventing an independent license statement for the downloaded file.

This local archive preserves the original scientific-data bytes. New raw-field organization, source offsets, conservative parsing, and verification are transformations made for this project. Numerical values were not revised. No license grant for the applicant's unrelated patent draft, new code, or other repository content is added by this attribution file.

Only the relevant publication notice, cutoff, and schema information were inspected. No complete publisher PDF, figures, reference list, or commentary table is republished in this archive. The short notice above is the only direct quotation; the rest of this file is a paraphrase or an explanation of this archive's handling.
